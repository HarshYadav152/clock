# Analog Clock Project ⌚

A beautiful, interactive analog clock built with HTML, CSS, and JavaScript. This project showcases real-time clock movements with smooth animations and a sleek dark-themed interface.

## 📌 Live Demo
[View Live Demo](#) *(Add your deployed link here)*

## ✨ Features

- **Real-time Analog Display** - Smooth sweeping second hand movement
- **Digital Time Readout** - 12-hour format with AM/PM indicator
- **Elegant Dark Theme** - Eye-friendly dark gradient background
- **Responsive Design** - Adapts seamlessly to different screen sizes
- **Smooth Animations** - 60fps hand movements using requestAnimationFrame
- **Glass Morphism Effects** - Modern UI with backdrop filters and shadows

## 🛠️ Technologies Used

- **HTML5** - Semantic markup structure
- **CSS3** - Flexbox, gradients, animations, glass effects
- **JavaScript** - DOM manipulation, Date object, smooth animations

## 🎨 Customization

You can easily customize the clock:

- **Colors** - Modify CSS variables in the style section
- **Size** - Adjust `height` and `width` in `#clockcontainer`
- **Hand colors** - Change background gradients of `#hour`, `#minute`, `#second`
- **Theme** - Update background gradients in `body`

## 📱 Responsive Design

The clock automatically adjusts for:
- **Desktop** - Full-size display with optimal spacing
- **Tablet** - Scaled down while maintaining proportions
- **Mobile** - Compact view with adjusted font sizes
